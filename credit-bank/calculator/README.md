# Calculator Microservice
Микросервис для расчёта кредитных предложений и полного расчёта итоговых параметров кредита

## Описание
Приложение предоставляет два REST API endpoints для расчёта кредитных условий:
### 1. POST '/calculator/offers'
Возвращает список кредитных предложений

- Формируется **4 варианта предложения** с комбинациями:
    - 'isInsuranceEnabled' - страховка включена/выключена
    - 'isSalaryClient' - зарплатный клиент или нет
- Логика формирования кредитного предложения:
    - Базовая ставка берётся из 'LoanProperties' (application.yaml)
    - Если включена страховка, сумма кредита увеличивается на стоимость страховки, а ставка уменьшается на значение 'isSalaryClient'
    - Если клиент зарплатный, ставка уменьшается на значение 'salaryClientDiscount'
- Предложения сортируются от худшего к лучшему (чем меньше ставка, тем лучше)

### 2. POST '/calculator/calc'
Выполняет полный расчёт параметров кредита

- Происходит **скоринг** данных, вычисляется итоговая ставка (rate):
  - Рабочий статус: Безработный → отказ; Самозанятый → ставка увеличивается на 2; Владелец бизнеса → ставка увеличивается на 1
  - Позиция на работе: Менеджер среднего звена → ставка уменьшается на 2; Топ-менеджер → ставка уменьшается на 3
  - Сумма займа больше, чем 24 зарплат → отказ
  - Семейное положение: Замужем/женат → ставка уменьшается на 3; Разведен → ставка увеличивается на 1
  - Возраст менее 20 или более 65 лет → отказ
  - Пол: Женщина, возраст от 32 до 60 лет → ставка уменьшается на 3; Мужчина, возраст от 30 до 55 лет → ставка уменьшается на 3; Не бинарный → ставка увеличивается на 7
  - Стаж работы: Общий стаж менее 18 месяцев → отказ; Текущий стаж менее 3 месяцев → отказ
- Вычисляется размер ежемесячного платежа (monthlyPayment)
- Вычисляется полная стоимость кредита (psk)
- Составляется график ежемесячных платежей (List<PaymentScheduleElementDto>)

## Конфигурация
Все параметры кредита настраиваются через 'application.yaml'

### application.yaml
    loan:
      base-rate: 20
      insurance-cost: 100000
      insurance-discount: 3
      salary-client-discount: 1
- base-rate - базовая годовая процентная ставка
- insurance-cost - стоимость страховки
- insurance-discount - уменьшение ставки при включении страховки
- salary-client-discount - уменьшение ставки для зарплатного клиента

## Запуск приложения

### Локально
    - mvn clean package
    - java -jar target/calculator-*.jar

Приложение будет доступно по адресу:
- http://localhost:8081

## Swagger (API документация)

После запуска приложения Swagger UI доступен по адресу:
- http://localhost:8081/swagger-ui/index.html
